# Jyotirmayee Acharya | Academic Portfolio
Static site (HTML, CSS, JavaScript) for GitHub Pages.

## Files
- `index.html` page structure
- `style.css` design
- `script.js` interactivity and your editable projects/achievements
- `assets/profile.jpg` your photo (add it)
- `assets/CV.pdf` your CV (add it)

## Publish
1. Add `profile.jpg` and `CV.pdf` to `assets/`.
2. In your repo on github.com, click Add file > Upload files, drag in everything (keep the `assets` folder), then Commit changes.
3. Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
4. Wait 1-2 minutes, then open the URL shown on that page.
